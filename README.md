# -Arduino-Electronics-Projects
This repository contains some of my beginner projects developed while learning Arduino, electronics, simulation, and robotics. The projects were designed and tested using Wokwi and Tinkercad and helped me understand how electronic components, sensors, and Arduino programming work together.

1. Traffic Light Simulation

Description-
Designed and simulated a basic traffic light control system using an Arduino Uno and red, yellow, and green LEDs in Tinkercad.
The Arduino controls the LEDs in a specific sequence to simulate the operation of a real traffic signal.

Components-
- Arduino Uno
- Red LED
- Yellow LED
- Green LED
- Resistors
- Jumper wires

Concepts Learned-
- Digital output control
- LED control
- Timing using `delay()`
- Basic Arduino programming
- Understanding sequential control systems

 Technologies-
Arduino
Tinkercad
C/C++ 
Digital Electronics

 2. Line-Following Robot Car

 Description-
Designed and simulated a basic line-following robot car using an Arduino Uno and IR sensors.
The IR sensors detect the position of a path and provide input to the Arduino. Based on the sensor readings, the Arduino determines how the robot should move.
This project helped me understand the basic principles behind sensor-based decision making and autonomous robots.

Components-
- Arduino Uno
- IR sensors
- DC motors
- Motor driver
- Robot chassis
- Wheels
- Battery/power source

Concepts Learned-
- Sensor-based control
- IR sensor operation
- Motor control
- Autonomous movement
- Conditional programming
- Basic robotics

3. Happy Birthday Arduino Project

 Description-
Created an interactive Arduino project that plays the Happy Birthday melody using a buzzer while displaying messages on an LCD.
LEDs were also included as visual indicators. The project combines multiple components and demonstrates how Arduino can control different outputs simultaneously.

Components-
- Arduino Uno
- LCD display
- Buzzer
- LEDs
- Resistors
- Breadboard
- Jumper wires

 Concepts Learned-
- LCD interfacing
- Buzzer control
- Playing melodies using Arduino
- LED control
- Combining multiple electronic components
- Arduino programming
